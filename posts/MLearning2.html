Machine Learning(二) 单变量线性回归与梯度下降

发表于2026-04-26|更新于2026-05-13|AI机器学习
|总字数:2.3k|阅读时长:9分钟|浏览量:

线性回归的模型描述

在监督学习模型里，我们通常有一个已知的数据集，称为训练集(Training Set)。而监督学习要做的就是让计算机根据训练集数据实现输出。

在继续进行之前，我们先做如下记号规定

  • mmm：训练样本的数量
  • x\boldsymbol{x}x：输入变量
  • y\boldsymbol{y}y：输出变量
  • (x,y)(x,y)(x,y)：一个训练样本
  • (x(i),y(i))(x^{(i)},y^{(i)})(x(i),y(i))：训练集中索引为 iii 的训练样本
  • hhh：模型使用的假设函数(Hypothesis Function)，构造从 x\boldsymbol{x}x 到 y\boldsymbol{y}y 的映射

假设函数可以有多种形式，当 hhh 为线性函数形式时，亦即

h(x)=θ0+θ1xh(x)=\theta_0+\theta_1x h(x)=θ0​+θ1​x

此时对应的模型称为线性回归模型(Linear Regression)，其对应的假设函数也可记为 hθ(x)h_{\theta}(x)hθ​(x)。在本小节中，我们讨论的都是只包含一个输入变量的线性回归问题，因此也称为单变量线性回归模型。

代价函数

代价函数的数学定义

在线性回归模型的假设函数中，参数 θ0,θ1\theta_0,\theta_1θ0​,θ1​ 是可以任意选取的，因此如何有效选取这些参数是个重要的问题。

为了选取适当的 θ0,θ1\theta_0,\theta_1θ0​,θ1​，我们需要让 h(x)h(x)h(x) 对于训练集中的的每一个 x(i)x^{(i)}x(i)，输出一个值 yyy 且使得 yyy 与 y(i)y^{(i)}y(i) 的差距尽可能小。这个问题也可以被叙述成最小化问题，我们需要找到一对值 (θ0,θ1)(\theta_0,\theta_1)(θ0​,θ1​)，使得各个训练数据的输出误差都尽可能小。用数学语言表述如下

Find a pair of value (θ0,θ1)s.t.min⁡12m∑i=1m(hθ(x(i))−y(i))2\text{Find a pair of value }(\theta_0,\theta_1)\quad s.t.\min \frac{1}{2m}\sum_{i=1}^{m}\Big(h_{\theta}(x^{(i)})-y^{(i)}\Big)^2 Find a pair of value (θ0​,θ1​)s.t.min2m1​i=1∑m​(hθ​(x(i))−y(i))2

在上式子中，θ0,θ1\theta_0,\theta_1θ0​,θ1​ 是影响后一部分函数取值的变量，因此我们定义代价函数(Cost Function)

J(θ0,θ1)=12m∑i=1m(hθ(x(i))−y(i))2J(\theta_0,\theta_1)=\frac{1}{2m}\sum_{i=1}^{m}\Big(h_{\theta}(x^{(i)})-y^{(i)}\Big)^2 J(θ0​,θ1​)=2m1​i=1∑m​(hθ​(x(i))−y(i))2

代价函数也称作平方误差函数，因为求和部分是误差项 hθ(x(i))−y(i)h_{\theta}(x^{(i)})-y^{(i)}hθ​(x(i))−y(i) 的平方，使得求和内容均非负。平方误差函数解决大多数线性回归问题的较优选择。故问题转化为

Find a pair of value (θ0,θ1)s.t.min⁡J(θ0,θ1)\text{Find a pair of value }(\theta_0,\theta_1)\quad s.t.\min J(\theta_0,\theta_1) Find a pair of value (θ0​,θ1​)s.t.minJ(θ0​,θ1​)

代价函数的讨论

我们先考虑 θ0=0\theta_0=0θ0​=0 的情况，也就是只保留线性部分。此时代价函数是关于 θ1\theta_1θ1​ 的函数

J(θ1)=12m∑i=1m(hθ(x(i))−y(i))2=12m∑i=1m(θ1x(i)−y(i))2\begin{aligned}J(\theta_1)&=\frac{1}{2m}\sum_{i=1}^{m}\Big(h_{\theta}(x^{(i)})-y^{(i)}\Big)^2\\ &=\frac{1}{2m}\sum_{i=1}^{m}\Big(\theta_1x^{(i)}-y^{(i)}\Big)^2\end{aligned}J(θ1​)​=2m1​i=1∑m​(hθ​(x(i))−y(i))2=2m1​i=1∑m​(θ1​x(i)−y(i))2​

通过描点绘图等方法不难看出，代价函数 JJJ 是关于 θ1\theta_1θ1​ 的二次函数，且二次项系数为正。由二次函数的图像特点可以知道，此时一定存在一个 θ1\theta_1θ1​ 使得函数取得最小值，这一点是比较重要的。

[{"url":"/img/mlearning/m2f2.png","alt":"简化版代价函数","title":""}]

在简化版代价函数的基础上，引入 θ0\theta_0θ0​ 导致代价函数 JJJ 变成了一个多元函数。为了直观地解决最小化问题，我们可以通过绘制等值线图如下。

[{"url":"/img/mlearning/m2f3.png","alt":"代价函数的等值线图","title":""}]

在每一条等值线上，不同的 θ0,θ1\theta_0,\theta_1θ0​,θ1​ 对应的代价函数值是一样的。如果能够借助计算机工具绘制出这些等值线图，我们便可以直观找出满足条件的参数 θ0,θ1\theta_0,\theta_1θ0​,θ1​。然而，可视化通常是困难的。

梯度下降

梯度下降的数学定义

现在来介绍一种数学方法，能够实现代价函数的最小化。我们不妨先看看更一般的情况

  • 代价函数 JJJ 是关于 nnn 个参数 θ0,θ1,⋯ ,θn−1\theta_0,\theta_1,\cdots,\theta_{n-1}θ0​,θ1​,⋯,θn−1​ 的函数
  • 需要找出一对值 (θ0,θ1,⋯ ,θn−1)(\theta_0,\theta_1,\cdots,\theta_{n-1})(θ0​,θ1​,⋯,θn−1​)，使得 JJJ 最小。

梯度下降(Gradient Descent)法的流程如下

  1. 任意选取一对值 (θ0,θ1,⋯ ,θn−1)(\theta_0,\theta_1,\cdots,\theta_{n-1})(θ0​,θ1​,⋯,θn−1​)
  2. 通过某种变换改变 (θ0,θ1,⋯ ,θn−1)(\theta_0,\theta_1,\cdots,\theta_{n-1})(θ0​,θ1​,⋯,θn−1​) 的值
  3. 重复上述过程直到我们找到 JJJ 的最小值或局部最小值

现在回到线性回归模型上，我们规定梯度下降法中的某种变换如下

θj:=θj−α∂∂θjJ(θ0,θ1),(j=0,1)\theta_{j}:=\theta_j-\alpha\frac{\partial}{\partial \theta_j}J(\theta_0,\theta_1),\quad(j=0,1) θj​:=θj​−α∂θj​∂​J(θ0​,θ1​),(j=0,1)

在上式中，符号:=表示右式赋值给左式，∂\partial∂ 是偏导符号。我们要求 θ0\theta_0θ0​ 和 θ1\theta_1θ1​ 是一起变换的，因为 JJJ 是同时关于 θ0,θ1\theta_0,\theta_1θ0​,θ1​ 的函数。

该算法由梯度(Gradient)的数学性质保证。一个多元函数 fff 在某点 PPP 的梯度 ∇f∣P\nabla f|_{P}∇f∣P​ 对应着其增长率最大的方向，其负方向 −∇f∣P-\nabla f|_{P}−∇f∣P​ 对应着函数降低最快的方向。

学习率

在变换中，α\alphaα 表示学习率(Learning Rate)，其不同取值对算法有不同影响。

  • 如果 α\alphaα 很小，那么梯度下降的过程会很“缓慢”
  • 如果 α\alphaα 很大，那么梯度下降的过程会很“迅速”，但可能不收敛
[{"url":"/img/mlearning/m2f4.png","alt":"学习率对梯度下降的影响","title":""}]

如何选取学习率 α\alphaα 的取值也是一个问题，本节不涉及。

梯度下降法的局限性

  1. 梯度下降法只能保证找到局部最小值，不能保证找到最小值。当前状态已经处于局部最小值时，根据多元函数的性质，函数在该点对各个变元的偏导为0，因此算法只能收敛于此局部最小点。

  2. 固定 α\alphaα 时，梯度下降法的迭代过程会越来越缓慢。此时可以适当增大学习率 α\alphaα。

线性回归的梯度下降法

数学模型

为了编写线性回归的梯度下降算法，我们必须要搞清楚代价函数 JJJ 对 θ0,θ1\theta_0,\theta_1θ0​,θ1​ 的偏导是什么。为此，我们需要进行适当的数学推导。展开求和项后求偏导，并代入算法，结果如下

{θ0:=θ0−α⋅1m∑i=1m(hθ(x(i))−y(i))θ1:=θ1−α⋅1m∑i=1m(hθ(x(i))−y(i))x(i)\begin{cases}\theta_0:=\theta_0-\alpha\cdot\dfrac{1}{m}\displaystyle\sum_{i=1}^{m}\Big(h_{\theta}(x^{(i)})-y^{(i)}\Big)\\\\ \theta_1:=\theta_1-\alpha\cdot\dfrac{1}{m}\displaystyle\sum_{i=1}^{m}\Big(h_{\theta}(x^{(i)})-y^{(i)}\Big)x^{(i)}\end{cases}⎩⎨⎧​θ0​:=θ0​−α⋅m1​i=1∑m​(hθ​(x(i))−y(i))θ1​:=θ1​−α⋅m1​i=1∑m​(hθ​(x(i))−y(i))x(i)​

线性回归模型的代价函数总是一个凸函数(Convex Function)，直观上看是一个开口向上的碗型形状，且只有一个全局最小值点。这也就是说，线性回归模型是可以利用梯度下降法找到全局最优解的。

[{"url":"/img/mlearning/m2f5.png","alt":"线性回归模型的代价函数","title":""}]

梯度下降算法是一个迭代算法。当其每一次迭代都遍历所有的训练集数据时，称该梯度算法为Batch梯度下降；除了梯度下降法，还有正规方程组法等可以求解代价函数的最小值。
