L1. Flow and Diffusion

Key ideas

Let us define what it means to generate something. In machine learning, we call a data distribution as the space of data itself, and denote it as pdatap_{\mathrm{data}}pdata​. Mathematically, one can think of pdata as a probability density, i.e. a function

pdata:Rd→R⩾0p_{\mathrm{data}}:\mathbb{R}^d \rightarrow \mathbb{R}_{\geqslant0} pdata​:Rd→R⩾0​

A generative model is a machine learning model that allows us to generate samples from pdatap_{\mathrm{data}}pdata​. When generating a new object zzz, we say that we sample it from the data distribution pdatap_{\mathrm{data}}pdata​.

A dataset consists of a finite number of samples z1,⋯ ,zN∼pdataz_1,\cdots,z_N \sim p_{\mathrm{data}}z1​,⋯,zN​∼pdata​. In many cases, we want to generate an object conditioned on some data yyy. We can rephrase this as sampling from a conditional distribution pdata(⋅∣y)p_{\mathrm{data}}(\cdot|y)pdata​(⋅∣y), where yyy is a conditioning variable.

In the following chapters, we will talk about how to realize this sampling process.

Flows

We start by defining ordinary differential equations (ODEs). Every ODE is defined by a vector field uuu, which has both spatial feature x∈Rdx\in\mathbb{R}^dx∈Rd and temporal feature t∈[0,1]t\in[0,1]t∈[0,1] as follows

u:Rd×[0,1]→Rd,(x,t)↦ut(x)u:\mathbb{R}^d\times[0,1]\rightarrow\mathbb{R}^d,\quad (x,t)\mapsto u_t(x) u:Rd×[0,1]→Rd,(x,t)↦ut​(x)

An ODE imposes a condition on a trajectory: we want a trajectory X=XtX=X_tX=Xt​ that follows along the lines of the vector field utu_tut​, starting at the point x0x_0x0​. This could be described as an ODE equation

ddtXt=ut(Xt),X0=x0\frac{\mathrm{d}}{\mathrm{d}t}X_t=u_t(X_t),\quad X_0=x_0 dtd​Xt​=ut​(Xt​),X0​=x0​

We may now ask: if we start at X0=x0X_0 = x_0X0​=x0​ at t=0t = 0t=0, where are we at time ttt (what is XtX_tXt​)? This question is answered by a function called the flow, which is a solution to the ODE

ψ:Rd×[0,1]→Rd,ψt(X0)=Xt\psi:\mathbb{R}^d\times[0,1]\rightarrow\mathbb{R}^d,\quad \psi_t(X_0)=X_t ψ:Rd×[0,1]→Rd,ψt​(X0​)=Xt​

Therefore, vector fields, ODEs, and flows are, intuitively, three descriptions of the same object: vector fields define ODEs whose solutions are flows.

If u:Rd×[0,1]→Rdu:\mathbb{R}^d\times[0,1]\rightarrow\mathbb{R}^du:Rd×[0,1]→Rd is continuously differentiable with a bounded derivative, then the ODE above has a unique solution given by a flow ψt\psi_tψt​.

We can now construct a generative model via an ODE by making the vector field a neural network vector field utθu^{\theta}_tutθ​. Specifically, we choose an initial distribution pinit∼N(0,Id)p_{\mathrm{init}}\sim \mathcal{N}(0,I_d)pinit​∼N(0,Id​). A flow model is then described by the ODE

where ψtθ\psi^{\theta}_tψtθ​ describes the flow induced by utθu^{\theta}_tutθ​. In order to compute the flow, we need to simulate the ODE. One way is to use the Euler method with the iteration steps Xt+h=Xt+hut(Xt)X_{t+h}=X_t+hu_t(X_t)Xt+h​=Xt​+hut​(Xt​), which hhh is very small.

Diffusions

Stochastic differential equations (SDEs) extend the deterministic trajectories from ODEs with stochastic trajectories. A stochastic trajectory is commonly called a stochastic process (Xt)0⩽t⩽1(X_t)_{0\leqslant t\leqslant 1}(Xt​)0⩽t⩽1​ and is given by

X:[0,1]→Rd,t↦Xt is a random trajectory for every random XX:[0,1]\rightarrow\mathbb{R}^d,\quad t\mapsto X_t\text{ is a random trajectory for every random } X X:[0,1]→Rd,t↦Xt​ is a random trajectory for every random X

SDEs are constructed via a Brownian motion. You can think of a Brownian motion as a continuous random walk. Specifically, A Brownian motion W=(Wt)0⩽t⩽1W = (W_t)_{0\leqslant t\leqslant 1}W=(Wt​)0⩽t⩽1​ is a stochastic process such that W0=0W_0 = 0W0​=0, the trajectories t↦Wtt \mapsto W_tt↦Wt​ are continuous, with the following features

  1. Wt−Ws∼N(0,(t−s)Id)W_t-W_s\sim\mathcal{N}(0,(t-s)I_d)Wt​−Ws​∼N(0,(t−s)Id​) for all 0⩽s⩽t0\leqslant s\leqslant t0⩽s⩽t.
  2. For any 1⩽t0⩽t1⩽⋯⩽tn=11\leqslant t_0\leqslant t_1\leqslant\cdots\leqslant t_n=11⩽t0​⩽t1​⩽⋯⩽tn​=1, the increments Wti−Wti−1W_{t_i}-W_{t_{i-1}}Wti​​−Wti−1​​ are independent random variables.
  3. We can easily simulate a Brownian motion approximately with step size h>0h > 0h>0 by setting W0=0W_0 = 0W0​=0 and updating Wt+h=Wt+hεW_{t+h}=W_t+\sqrt{h}\varepsilonWt+h​=Wt​+h​ε, where ε∼N(0,Id)\varepsilon\sim\mathcal{N}(0,I_d)ε∼N(0,Id​) is a random Gaussian noise.

A stochastic differential equation(SDE) is usually denoted in the following symbolic notation

dXt=ut(Xt)dt+σtdWt,X0=x0\mathrm{d}X_t=u_t(X_t)\mathrm{d}t+\sigma_t\mathrm{d}W_t,\quad X_0=x_0 dXt​=ut​(Xt​)dt+σt​dWt​,X0​=x0​

where σt⩾0\sigma_t \geqslant 0σt​⩾0 describes the diffusion coefficient. Finally, note that every ODE is also an SDE – simply with a vanishing diffusion coefficient σt=0\sigma_t = 0σt​=0. Therefore, when we speak about SDEs, we consider ODEs as a special case.

How might we simulate an SDE? The simplest such scheme is known as the Euler-Maruyama method, and is essentially to SDEs what the Euler method is to ODEs. Using the Euler-Maruyama method, we initialize X0=x0X_0 = x_0X0​=x0​ and update iteratively via

Throughout this chapter, a diffusion model consists of a neural network utθu^{\theta}_tutθ​ with parameters θ\thetaθ that parameterize a vector field and a fixed diffusion coefficient σt\sigma_tσt​ as follows

  • Neural networkutθ:Rd×[0,1]→Rd,(x,t)↦utθ(x)u_t^{\theta}:\mathbb{R}^d\times[0,1]\rightarrow\mathbb{R}^d,\quad (x,t)\mapsto u^{\theta}_t(x)utθ​:Rd×[0,1]→Rd,(x,t)↦utθ​(x)
